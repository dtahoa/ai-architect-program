# AI Architect Program

This repository contains the curriculum structure for an AI architecture program.

## Structure

- `modules/` - Core learning modules.
- `workshops/` - Guided exercises and applied sessions.
- `capstone/` - Capstone requirements, rubric, and pass/fail criteria.
- `adr/` - Architecture decision records.
- `diagrams/` - Architecture and system diagrams.

## Program Modules

1. AI Fundamentals
2. AI Architecture Principles
3. AI System Design
4. Data Architecture for AI
5. Model Selection and Evaluation
6. Prompting and Agentic Workflows
7. AI Platform Engineering
8. Security, Privacy, and Governance
9. Production Operations and Observability
10. Technical Leadership
